#  Trino types

- Boolean (`true` or `false`)
- Integer or Int (`12`, `-14`)
- Real, Double, Number (`3.14`, `-9.8345`) [floating point, inexact]
- Decimal (3.29) [exact up to 38 digits]
- Varchar - a string (`'Hello!'`) ["var" = variable length, "char" = character, note: use single quote!]
- Varbinary - binary data
- Date (`DATE '2026-12-31'`) [note: year-month-day with the word "DATE"]
- Time (`TIME '01:58:36.77'`) (note the word "TIME")
  - also have a time with time zone

## NOTE: for MySQL don't use "DATE" word ... and need a length for varchar

ANSI: no Boolean?, INTEGER, REAL, DECIMAL, CHARACTER and CHARACTER VARYING

# INSERT INTO 

INSERT INTO table_name VALUES (column, column, column) (val,val,val) ... 

IMPORTANT: single quote are for strings, double for DB objects. 

```
INSERT INTO countries (code, name, continent) VALUES
('A7', 'Kepler Dome', 'Moon'),
('A8', 'Blip', 'Moon'),
('A9', 'Blah', 'Moon'),
('A10', 'Blip', 'Moon'),
('A11', 'Blah', 'Moon'),
('A12', 'Blip', 'Moon');
```
